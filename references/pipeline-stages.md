# 十阶段流水线细则

每阶段格式：**输入 → 动作 → 输出 → 留痕 → 人工点（✋）**。贯穿铁律见 SKILL.md「Built-in Safeguards」。

## ① SEARCH DESIGN（检索式设计）

- **输入**：研究方向一句话 + 检索截止日期。
- **动作**：概念分解为核心词（研究对象）× 方法词（鉴别/检测等）两组；按库语法草拟——CNKI 用 `SU=`（主题，无引号，`*` 乘 `+` 加）、PubMed 用字段全称（`[Title/Abstract]`，弃用缩写 `[TA]`）、WoS 用 `TS=`；每式先做 **0 命中预检**（官网或 API 试跑，PubMed 可用 eutils esearch 试点），0 命中语法不得进入正式检索。
- **输出**：`01_检索记录表.xlsx`（模板见 `templates/search-record-template.md`：式号/数据库/语法/命中数/检索日期/导出状态）。
- **留痕**：记录表即留档；预检的 API 试测命令与返回一并留存。
- **✋ 人工**：确认检索式集合与截止日期。

## ② TRI-DB SEARCH + RECORDING（三库检索 + 录屏）

- **输入**：确认后的检索式表、已登录的 CDP Chrome（9222）。
- **动作**：见 `references/cdp-drivers.md` 三库驱动差异。铁律：先启录制器后操作。每条检索式独立会话：逐字符真实键入 → 真实点击 → 捕获命中数（选择器见驱动手册）→ STATE（URL+标题+正文摘要）→ 截图。
- **输出**：mp4×N（每式一段）、单式截图×N、当日实况命中记录。
- **留痕**：manifest 登记每段的**留档命中 vs 当日实况**；人机验证/等待如实入镜。
- **✋ 人工**：会话过期时扫码（会话自愈环）。

## ③ EXPORT CSV（三库导出）

- **输入**：检索结果页。
- **动作**：CNKI 反爬强——需人工经机构登录手动导出（单次上限约 500 条，超过分批；WoS 全量导出须在新活动标签页选「Records 1–N」而非页面默认，否则截断）。Agent 执行的任何导出操作须先启录制器。
- **输出**：`.enw` / `.txt` / `.csv` 原件（**唯一口径**），合并计数（如 CNKI 1,286 + PubMed 64 + WoS 359 = 1,709）。
- **留痕**：原件文件本身；记录表补导出状态列。
- **注意**：记录表"命中数"与"实际导出数"是两套口径（命中=查询返回，导出=当时实际导出，含跨式重复），两套都要留档并在 manifest 说明。

## ④ DEDUP（去重）

- **动作**：库内去重 → 跨库去重（DOI 优先，题名精确/前缀/包含/0.85 相似度兜底的**确定性匹配函数**，全流程只用这一个函数）；只删真重复，同名异源标记不删。
- **输出**：去重后合并表（一行 = 一篇，列含 Source/Title/Abstract/DOI）+ 去重台账（库内删 N1、跨库删 N2）。
- **留痕**：匹配函数即代码，重放可验证。

## ⑤ I/E CRITERIA（纳排标准）

- **动作**：书面化标准 → 排除码（E1 研究对象不符/E2 研究内容不符/E3 仅作对照……）+ 纳入码（I1-I7）+ **诱骗词剥离**（如"八角枫/八角莲"含"八角"但非目标属）+ 冻结为脚本配置（词表、逻辑、排除码全部进代码）。
- **输出**：纳排标准文档 + 脚本配置段。
- **✋ 人工**：确认标准后冻结；此后任何修改必须记录原因、日期、影响。

## ⑥ SCREENING（初筛）

- **动作**：规则重放脚本全量判定 → 与历史判定（如有）逐条比对 → 差异即纠偏（逐条标记）→ 人工 rescue（只 rescue "终筛已纳入但被规则误排"者，逐条注明理由与匹配依据）。
- **输出**：纳排总表（含列：结果/排除码/原因/历史结果/差异标记/人工复核）+ 核心严筛表（双关键词 A×B 优先获取集）+ 差异统计。
- **留痕**：四步过程证据页（输入 CSV 摘录/脚本全文/输出 CSV 摘录/统计）截图；**单人筛选如实声明**，不得写成独立双人筛选。

## ⑦ FULL-TEXT GET（全文获取）

- **动作**：按获取渠道分四类出可点击清单（见 SKILL.md Quick Start 模式 A）：OA 直链 / 出版商订阅（EZproxy `/login?url=` 包装）/ 中文库 / 手工检索。下载后逐条登记台账并做**磁盘复核**（台账=磁盘才可报数）。Agent 的 OA fetch 与出版商页面操作先启录制器。
- **输出**：PDF 库（分类文件夹存放、中文命名或规范命名）+ 台账（已获取/放弃/重复覆盖三类合计=总行数）。
- **✋ 人工**：因无法获取全文而排除的文献必须经用户确认，不可自行排除。

## ⑧ CLOSE READING（精读）

- **动作**：逐篇建档精读表（标题/来源/发表日期按近优先/摘要/方法/创新点/值得纳入的理由），按分类生成分类表；区分"全文证据库全量评估"与"筛选"两件事，勿把评估动作当筛选阶段。
- **输出**：精读汇总表（含保留 sheet 与淘汰 sheet）。

## ⑨ FINAL I/E（终筛）

- **动作**：从精读池终筛纳入集合；**确定性匹配回核构成**——终筛 N = 重筛纳入池内 N1 + 其他来源 N2 + 漏网 0（漏网=0 才算自洽）；模糊匹配用与 ④ 相同的唯一匹配函数，禁止临时换函数。
- **输出**：终筛表 + 二次淘汰表 + 构成回核记录。
- **✋ 人工**：终筛确认。

## ⑩ FOLDER + PPT（文件夹与立项 PPT）

- **动作**：生成标准文件夹骨架（01_调研计划 / 02_原始文献 / 03_文献管理 / 04_全文文献 / 05_精读产出 / 05_输出文档 / 06_脚本工具 / 07_法规标准 / _归档，空目录即删，历史件只归档不删除，整理清单留痕）；生成立项 PPT：数字主线唯一口径、每页数字配三层证据（留档原件/静态截图/内嵌录屏视频）、检索页附官网截图墙与录屏条。
- **输出**：项目文件夹 + PPT（视频内嵌，`add_movie` + 末帧封面）。
- **留痕**：整理清单（何物何时归档/删除）。

## 人工登录与下载操作（A 模式 / ⑦ 阶段配套）

### 首次登录（一次性，之后 A/B 共用会话）

1. 用带调试端口的 Chrome（`--remote-debugging-port=9222`）打开机构门户或任一 EZproxy 链接。
2. 跳转至 CAS 统一认证页（如 `login.must.edu.mo`）→ 用 **WeMust App 扫码**或校园门户账号登录。
3. 登录后回到目标页即已带机构权益；会话有时效（数小时级），过期由会话自愈环检测并再次请用户扫码。

### 逐篇下载（清单配合）

1. 在**同一浏览器**中打开 HTML 下载清单。
2. 逐篇点击清单链接 → 进入出版商页面 → 点「Download PDF」保存至对应分类文件夹。
3. **认证协议差异**：不同出版商走不同协议——SpringerLink 通常 CAS、ScienceDirect / Taylor & Francis 走 Shibboleth。若出现"未登录"，点页面上的「机构登录 / Institutional login / Sign in via your institution」→ 搜并选择本校 → 跳转后即正常，属预期现象。
4. **已登录仍跳 Purchase / Add to cart** = 学校未订阅该期刊，**不要反复重试**；改走 OA 镜像或馆际互借（ILL），并在清单中把该篇状态改为"无订阅"。
5. **要求单独注册会员**的特例（部分会议/SciTePress）：标记"需人工处理"。
6. **中文库（知网）**：走学校"知网机构版"入口；批量下载需先用**个人账号**登录知网（微信/QQ/短信均可，仅机构登录无批量下载能力）；Web 端研学不支持导入 EndNote 格式，用桌面客户端或检索页批量下载。

### 与录屏铁律的关系

- 以上操作由**人工**完成，不强制录屏；Agent 代执行的部分（OA fetch、页面抓取）仍按铁律先启录制器。
- 登录过程中**不要**让 Agent 代输账号密码——凭据只存在于用户与 CAS 之间。

## 收官自检清单

- [ ] 每个关键数字都能从留档原件重算
- [ ] manifest 中留档/实况差异逐条有解释
- [ ] 纳排脚本重放结果 = 报告数字
- [ ] 终筛构成回核漏网 = 0
- [ ] 台账 = 磁盘
- [ ] PPT 内嵌视频可播放、数量与检索式一致
