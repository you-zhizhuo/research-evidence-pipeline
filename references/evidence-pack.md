# 证据装配规范（三层证据 + manifest + PPT + 文件夹）

## 三层证据体系

| 层 | 内容 | 地位 |
|---|---|---|
| 留档原件 | 记录表 xlsx、导出原件（.enw/.txt/CSV）、PDF 库 | **唯一口径**，所有数字从这里来 |
| 静态截图 | 检索结果页截图、证据页（PDF 逐页渲染）、标准/法规存档 | 过程实拍 |
| 过程录屏 | mp4（标签页/桌面）+ 末帧缩略图 | "当场性"证明，不充当数字来源 |

每层对应关系必须在 manifest 里可查：数字 ↔ 原件 ↔ 截图 ↔ 录屏。

## manifest（检索录屏清单）

由 `scripts/make_manifest.py` 生成 `检索录屏清单.md`，表列：

`编号 | 数据库 | 检索式 | 录屏当日命中 | 留档依据 | 文件 | 时长 | 大小`

规则：
- "留档依据"一律指向记录表/导出原件；当日实况差异**逐条如实标注**（如"27（留档 24）"），头部说明差异系收录动态。
- 留档未覆盖的式（如 W3 原式未留档）明确写"录屏仅覆盖 W1/W2"。
- 特别说明区放语法时效注记（如 PubMed `[TA]` 弃用 → 录屏用全称，留档原式不动）。
- 每条 mp4 抽末帧缩略图（`-sseof -1.5`）存 `thumbs/` 并校验非空。

## PPT 内嵌（`scripts/ppt_embed.py`）

- 缩略图条：目标页底部深色带 + 末帧缩略图行 + `编号·命中` 标签 + 磁盘路径 + 过程说明。
- 视频内嵌：`add_movie(mp4, L, T, W, H, poster_frame_image=缩略图, mime_type='video/mp4')` **原位替换**静态缩略图；COM 验证媒体对象数 = 检索式数。
- 铁律：python-pptx 复用形状坐标**全程 EMU**，`Inches()` 只用于字面量；OneDrive 环境一律 TEMP 副本编辑 → 杀 POWERPNT → 写回 → COM 复验。

## 项目文件夹骨架

```
{项目名}/
├── 01_调研计划            # 方向、检索式表、纳排标准
├── 02_原始文献            # 下载流水线产物（按来源分库/分类子目录）
├── 03_文献管理            # 记录表、去重表、纳排总表、核心严筛表（唯一口径区）
├── 04_全文文献            # PDF 库（分类子目录）+ 新闻与事件存档
├── 05_精读产出            # 精读汇总表（保留/淘汰分 sheet）+ 综述子目录
├── 05_输出文档            # evidence_screenshots（截图+证据页）、检索录屏、审计文件
├── 06_脚本工具            # 本阶段全部脚本（规则即代码）
├── 07_法规标准            # 标准/法规原件与官方页面存档
└── _归档                  # 历史过程件只归档不删除
```

命名：文献 PDF 用规范名（如 `PMID{pmid}_{作者}_{年}_{期刊}.pdf` 或中文题名）；**不同来源分开建子目录**；空目录即删；整理清单记录每次归档/删除。
