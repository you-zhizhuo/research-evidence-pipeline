# 检索式记录表模板（01_检索记录表.xlsx 的 schema）

检索式记录表是**留档唯一口径**的一部分：命中数以此为准，导出数与录屏实况都是对照。

## Sheet1：检索式（每式一行）

| 列 | 说明 | 示例 |
|---|---|---|
| 式号 | S001/S002…（CNKI）、P1/P2…（PubMed）、W1/W2…（WoS） | S001 |
| 数据库 | CNKI / PubMed / WoS | CNKI |
| 检索语法 | 完整语法（CNKI `SU=`、PubMed 字段全称、WoS `TS=`） | `SU=(八角+八角茴香)*(鉴别+检测)` |
| 命中数（检索日） | **留档口径** | 528 |
| 检索日期 | YYYY-MM-DD（冻结时点） | 2026-10-10 |
| 导出状态 | 未导出/已导出(.enw)/已导出(.txt)/已导出(CSV) + 件名 | 已导出(.enw)×7 |
| 导出条数 | 实际导出行数（与命中数是两套口径，含跨式重复） | 1286 |
| 复核记录 | 语法预检/重放结论（如 `[TA]` 弃用改全称） | 2026-10-21 [TA]→[Title/Abstract] |

## Sheet2：合并台账（导出后）

| 列 | 说明 |
|---|---|
| ID | 全局唯一号 |
| Source | 来源库（CNKI/PubMed/WoS） |
| Title / Abstract / DOI / 年份 / 期刊 | 题录字段 |
| 去重标记 | 保留/删除（删除必须真重复） |
| 初筛结果 / 排除码 / 排除原因 | ⑥ 阶段回填 |
| 核心严筛 | 是/否 |
| 全文状态 | 已获取/放弃/重复覆盖 + 文件名 |
| 精读编号 / 终筛结果 | ⑧⑨ 阶段回填 |

## 语法预检记录（附页或同表扩展列）

每式一行：试测方式（官网/ eutils）→ 试测语法 → 返回命中 → 结论（可用/弃用改写）。
教训样例：PubMed `[TA]` 已弃用（实测 0），改 `[Title/Abstract]`。
